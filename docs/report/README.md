# Báo cáo tiến độ

Các báo cáo tiến độ gửi giảng viên hướng dẫn, viết bằng tiếng Việt. Mỗi lần báo cáo là một
file `YYYYMMDD.md`, đặt tên theo ngày gửi, và viết ngắn để đọc nhanh theo năm phần:

1. **Tóm tắt kết quả:** 2–3 ý chính.
2. **Hiện trạng:** từng thành phần đang ở đâu.
3. **Nguyên nhân:** vì sao kết quả như vậy, vì sao có thay đổi.
4. **Hành động:** việc sắp làm và những điểm cần thầy cho ý kiến.
5. **Phụ lục:** chi tiết hành động và kết quả.
